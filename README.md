# VentaFácil
Sistema básico para gestionar clientes, productos y ventas.

## Módulos
- Clientes
- Productos
- Ventas

## Estructura
 - Controllers: coordinación 
 - Models: entidades 
 - Services: lógica 
 - Data: acceso a datos 
 - Views: interfaz 
 
## Control de versiones 
El proyecto utiliza Git y GitHub.

## Objetivo
Facilitar el registro y consulta de operaciones comerciales.
